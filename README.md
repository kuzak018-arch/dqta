# Dota 2 — песочница сборок

Статичный сайт для сборок предметов Dota 2: выбор героя, слоты инвентаря,
каталог предметов и этапы сборки с суммой золота. Только HTML, CSS и
JavaScript: без фреймворков, без сборки и без зависимостей. Работает на
GitHub Pages прямо из корня репозитория.

## Запуск локально

Сайт загружает `data/*.json` через `fetch` и использует ES-модули, поэтому
открыть `index.html` двойным кликом (`file://`) не получится. Нужен любой
статический HTTP-сервер, запущенный из корня репозитория:

```sh
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
2. Branch: нужная ветка, папка **/ (root)** → Save.
3. Через минуту сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

Все пути относительные, поэтому сайт работает и из подпапки. Файл `.nojekyll`
отключает обработку Jekyll, и GitHub Pages отдаёт файлы как есть.

## Как пользоваться

- **Герой** — список слева: поиск по имени, группы по основному атрибуту.
  Повторный клик снимает выбор.
- **Каталог** — справа: поиск по названию и фильтр по категории магазина.
- **Слоты** — 6 инвентаря, 3 рюкзака и 1 нейтральный. Нейтральные предметы
  кладутся только в нейтральный слот, обычные — только в инвентарь и рюкзак.
- **Секции** — «Старт», «Ранний», «Кор», «Ситуативные». Название правится
  прямо в заголовке, «+ Добавить секцию» создаёт новую, «×» удаляет.
  Под каждой секцией — количество предметов и сумма золота, в заголовке
  блока — общая сумма.

Перетаскивание:

| Откуда → куда                    | Что происходит                                       |
|----------------------------------|------------------------------------------------------|
| каталог → слот / секция          | предмет копируется, занятый слот заменяется         |
| секция → секция (или внутри)     | перенос, место вставки показывает золотая полоска    |
| слот ↔ слот, секция → слот       | перенос; если слот занят, предметы меняются местами  |
| слот / секция → каталог          | предмет убирается                                    |

Клик (тап) по предмету в слоте или секции убирает его, с клавиатуры —
Enter или Delete. Esc отменяет перетаскивание.

Drag & drop сделан на pointer events и одинаково работает с мышью, пальцем и
пером. На телефоне нужно коротко задержать палец на предмете (≈0,2 с), а потом
тянуть: быстрый свайп остаётся обычной прокруткой. Когда палец у края экрана
или панели, страница прокручивается сама, поэтому предмет из каталога можно
дотащить до секций внизу.

## Сохранение и ссылки

- Каждое изменение сохраняется в `localStorage` и сразу записывается в адрес
  страницы: `…/#b=<base64>`. Кнопка «Поделиться ссылкой» копирует адрес в
  буфер обмена.
- В ссылке лежит компактный JSON в base64 (URL-safe алфавит `-_`, без `=`):
  `{"v":1,"h":<id героя>,"s":[10 id слотов],"c":[["Старт",[id,…]],…]}`.
  Используются числовые `id` из `data/*.json`, поэтому ссылка короткая
  (типичная сборка — около 300 символов).
- При открытии ссылка важнее сохранённого: чужая сборка из ссылки становится
  текущей. Без `#b=` берётся сборка из `localStorage`. Битая ссылка или
  неизвестные `id` не ломают страницу: лишнее отбрасывается.
- «Сбросить» очищает героя, слоты и секции.

## Данные

- `data/items.json` и `data/heroes.json` скачаны из
  [odota/dotaconstants](https://github.com/odota/dotaconstants/tree/master/build)
  (ветка `master`, папка `build`).
- Иконки: `https://cdn.cloudflare.steamstatic.com` + поле `img` из этих файлов.
  Если CDN недоступен, на плитках показываются названия, а в шапке — сколько
  иконок не загрузилось.
- В `items.json` нет раздела магазина, поэтому раскладка по категориям
  (Расходуемые, Атрибуты, … Артефакты) задана вручную в `js/shop.js` по патчу
  7.41. Там же список скрытых предметов: удалённых из игры, дропов с Рошана и
  прочих служебных. Нейтральные предметы определяются по полю `tier`.

Обновить данные:

```sh
curl -fsSo data/items.json  https://raw.githubusercontent.com/odota/dotaconstants/master/build/items.json
curl -fsSo data/heroes.json https://raw.githubusercontent.com/odota/dotaconstants/master/build/heroes.json
```

Новый предмет, которого нет в `js/shop.js`, попадёт в категорию «Прочее».

Проверить, что все ссылки на иконки отдают картинки (Node.js 18+, без
зависимостей):

```sh
node tools/check-icons.mjs
```

## Структура

```
index.html             разметка
css/style.css          тёмная тема и адаптивная вёрстка
js/main.js             точка входа, обработчики
js/data.js             загрузка и нормализация data/*.json
js/shop.js             категории магазина и скрытые предметы
js/state.js            состояние сборки и операции над ним
js/render.js           отрисовка панелей
js/dnd.js              drag & drop на pointer events
js/share.js            base64-ссылка и localStorage
tools/check-icons.mjs  проверка ссылок на иконки
```
